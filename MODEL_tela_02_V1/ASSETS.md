# Assets

Quatro retratos extraídos da referência 02 por `MODEL_assets_v1/extrair_entrada.py`, com máscaras alpha estreitas delimitadas no script. O RGB fora dessas máscaras permanece idêntico à fonte; nenhuma imagem é reconstruída. Texto e ícones nativos cobrem as regiões de UI da fonte. Pixels exatamente sob UI raster estão indisponíveis. Manifesto em assets/manifest.json contém hashes; SVGs derivam de telas existentes ou são vetores locais.
