# MODEL — assets extraídos v1

Extração do mockup fornecido (1179 × 753 px), sem geração de pessoas, retoque ou distorção. Coordenadas em manifest.json: [esquerda, topo, direita exclusiva, base exclusiva]. Recortes mantêm os pixels e proporções originais. Os cantos das telas podem conter o fundo bege do mockup.

## Tela 03
- referencias/referencia-tela-03.png: tela completa, 203 × 404 px, com todos os elementos incorporados. É referência visual, não uma captura de navegador.
- assets/enzo-retrato-parcial.png: 201 × 242 px, trecho da foto entre os indicadores e o nome. Preserva Enzo, mas corta parte do corpo e não recupera o fundo completo.
- assets/icons/: reconstruções vetoriais aproximadas dos controles; não são os vetores originais. Use currentColor para definir a cor (exceto selo azul).

Não ampliar com largura e altura independentes. Para fotografia, usar object-fit: cover com posição calibrada. A foto parcial não contém informação suficiente para reproduzir o fundo integral da Tela 03. Esticá-la ou aplicá-la como fundo completo mudará enquadramento e escala. Para fidelidade >=9,0, permanece necessária a fotografia original ou uma fonte limpa equivalente do mesmo retrato.
